# Control surface

What this theme's sections hand over to the editor, and what was deliberately left out. Generated by
`tools/blocks.mjs` from the same list that writes every `block.json`, so the record and the manifests
cannot drift apart.

A ported section is changed from the admin, never by re-cutting it. The order, cheapest first: change a
field value; add the control or the variant that expresses the difference; re-cut markup only when no
control can express it.

## Opened on every section

Declared in each block's `block.json`, switched on in `theme.json`, and printed onto the section's own
root element by `prairie_ash_section_attrs()`, in the editor preview as well as on the page.

- Spacing: padding on all four sides, margin above and below, from the design's spacing scale.
- Colour: the section background and its running text colour, from the design's palette.
- Dimensions: minimum height.
- Background: a background image with its size and position.
- An anchor the client can link to.
- Visibility: hiding the section, and hiding it per viewport (core, nothing to declare).
- Per element: alignment, text size from the design's type scale and colour from the palette, for each
  heading, label, body and card text, in its own collapsed panel with a reset back to the design.
- The order and the number of repeating parts, inside the section's own repeater, with no cap.
- The layout variants the design itself contains, where it contains more than one (Styles panel).

## Narrowed for the whole site, with the reason

The client asked for colours and sizes from the theme presets only. So every control offers the design's own values
and no value of the client's own. These rows record that narrowing once for the site.

| Block | Capability | Decided | Reason |
|---|---|---|---|
| theme | color.custom | 2026-10-19 | The client asked for colours from the theme presets only, so the palette is the design's eleven colours with no picker for a colour of their own. |
| theme | typography.customFontSize | 2026-10-19 | The client asked for sizes from the theme presets only, so the type scale is the design's eleven text sizes with no field for a typed size. |
| theme | spacing.customSpacingSize | 2026-10-19 | The client asked for presets only, so spacing is the design's seven-step scale with no typed value. |
| theme | color.customGradient | 2026-10-19 | The design contains no gradient, and the client asked for presets only. |
| theme | typography.dropCap | 2026-10-19 | A drop cap belongs to the core paragraph block, which this theme does not offer between its sections. |
| theme | allowedBlocks | 2026-10-19 | Pages offer the theme's own sections only. A core block placed between two sections renders edge to edge with none of the design's type, a state the design does not contain. |
